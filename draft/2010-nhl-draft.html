How this draft review works

We keep the actual draft order and the team that made each selection. For each pick, we rank rated players selected later in the same draft, from all seven rounds. This is a set of independent comparisons; it does not simulate players being taken off a new draft board.

sorted by a three-season rating based on Hockey Reference Point Shares. We weight Point Shares and games 50/30/20, newest season first. With the newest weight set to 1, the score is weighted Point Shares divided by weighted games plus 20. The extra games add no Point Shares, keeping very small samples conservative. Players below 20 weighted games are marked Limited data. Goalie Point Shares use the existing 0.72 scaling factor. The bar shows percentile among all players with NHL appearances in the three-season window.
